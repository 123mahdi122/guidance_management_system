# Alumni Information Management System

A desktop-based Alumni Information Management System developed using Java Swing and MySQL.

## Features

- User Login
- User Registration
- Alumni Profiling
- Alumni Information Management
- CRUD Operations
- MySQL Database
- Printable Reports

## Technologies Used

- Java
- Java Swing
- Apache NetBeans
- MySQL
- XAMPP
- JDK 23
- Launch4j
- Inno Setup Compiler
